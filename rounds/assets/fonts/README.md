These fonts restore the Fraunces headings/wordmark and Inter body text from
`rounds-app-mockup.html`. They are bundled locally so branding also works offline.

Source: https://github.com/expo/google-fonts/tree/master/font-packages

- Fraunces SemiBold: `fraunces/600SemiBold/Fraunces_600SemiBold.ttf`
- Inter Regular, Medium, SemiBold and Bold: the corresponding weight folders in `inter/`

Both families use the SIL Open Font License; the full licenses are included here.
